Shared links now unfurl with a picture of the thing you shared, not just a card that names its
kind. A shared character arrives as its own portrait medallion with the hero's name, level, class
and AC · HP painted on the folio card; a campaign invite shows the table's name and how many
adventurers are seated. The image is drawn fresh for each link when it is fetched, so it always
matches what is live. Anything you have not shared — an unshared sheet, a locked invite, an unknown
link — still shows the plain designed card, exactly like every other page, and if a card ever fails
to draw it quietly falls back to that same card rather than breaking the link. Only a name, portrait
and a couple of numbers are ever shown, and only for a link you have actually shared.
