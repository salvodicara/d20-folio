Companions rail section + the shared companion stat-block card. A new "Companions"
section in the resources rail surfaces every feature-declared companion (Steel
Defender, Eldritch Cannon, Beast Master's Primal Companion) as a compact, always-
play-reachable row — name, AC, HP with ± steppers — that opens the full stat block
in one tap, so a companion is no longer buried thirty cards deep in the Features
tab. The Beast Master's Beast of the Land / Sea / Sky choice is finally live: a
variant picker on the shared card (Features tab + rail modal, one component) writes
the pick and re-scales the beast, with an undoable toast. The stat block moved into
one shared `CompanionStatBlockCard` so both mounts always agree. Spells can now
declare a companion too (the seam the pack's Homunculus Servant rides).
