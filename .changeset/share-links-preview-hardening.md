Link previews got safer. A campaign whose joins you have locked no longer unfurls its name — a
leaked invite link now says nothing at all, exactly like a code that never existed, so locking is
a complete kill switch rather than one that leaves the table's name on show. The preview service
also only ever builds a page from d20 Folio's own live hosts, so a forged request can never make a
shared link serve someone else's content, nor make the service call itself in circles and burn the
app's tiny budget. Links that describe nothing — unshared, locked, unknown — now return the site's
ordinary card, unchanged.
