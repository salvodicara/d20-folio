**Character creation now opens on a finished character.** Quick Start no longer hands you a blank
form: it arrives complete — species and lineage, background, ability scores in the class's
priority, the background's boosts, skills, spells, starting gear, languages and every follow-up
pick a feat asks for — with only the name left to type. Picking a different class rebuilds the
sheet from that class's ready-made build (and asks first if you have already changed something;
your name always stays). Everything remains editable exactly where it always was, and Guided is
untouched.
