Custom monsters + monster portraits — the surfaces. The encounter Add-monster modal's
Custom tab is now a reusable LIBRARY: creating a monster saves it (name · type · CR ·
notes · art), and every saved monster is re-addable to any encounter from a searchable
list, with edit and delete. Monsters now carry ART beside the hero portraits: every
encounter combatant shows an uploaded portrait, or the deterministic tinted-initial
monogram — the SAME letter fallback the party heroes use — so a monster with no art reads
consistently with the party. A per-monster portrait can be uploaded and cropped on the
compendium/bestiary monster view (a per-user override, remembered for every future add)
and on a saved custom monster (kept with its template) — reusing the same crop-and-upload
flow as character portraits. On the bestiary statblock the portrait seat is the empty
right-side space beside the ability table (vertically centred, reflowing above the stats
on narrow widths); the seal itself is the upload affordance (hover/click to edit, no
standing instructional caption).
