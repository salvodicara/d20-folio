Auto-narrated combat, Phase 2 (multi-target correlation): the DM-side reconciliation now fuses ONE declared multi-target action with the several HP drops the DM applied across the struck foes, rendering a single summary line with each target's real damage instead of separate per-target lines. The action's instance count bounds how many drops it may claim; a declared target with no in-window drop is omitted (never given an invented number); drops that can't cleanly match the set (over the bound, or a competing declaration on a shared target) mark the line uncertain. Single-target auto-attribution and miss lines are unchanged.
