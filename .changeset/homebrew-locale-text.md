Homebrew text can be written in some languages, not necessarily all: a homebrew spell, feature, weapon or item name and description (and a homebrew grant's label) may be a plain string, as every stored entry is, or a per-language text. Every screen shows it in the reader's language, else English, else whichever language was written. The edit forms change only the language being shown and keep the others. A held Concentration on a homebrew spell now finds the spell's mechanics from its stable id, not only from the old name-only form. Reader only: nothing writes per-language text yet.
