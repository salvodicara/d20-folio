Creation polish from the design audit: Randomize now rerolls the class you actually have (a class
picked in Guided used to be thrown away), and both destructive acts on the page — rerolling and
rebuilding as another class — ask the same way once you have changed something by hand, while an
untouched sheet is replaced silently. Swapping the background on an untouched sheet re-seeds the
ability boosts and class skills it owns instead of quietly emptying them far down the page. The
path cards finally show what each path promises on phones, and Randomize meets the touch-size
floor there.
