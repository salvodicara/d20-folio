# Reference products — campaign jobs (evidence file)

Scope: seven campaign jobs across reference products — behaviour, flow, information order and copy only; no visual judgements. Every fact carries a URL. "Capture:" = page a designer can open to screenshot. **unverified** = not confirmed on an official page. "(search excerpt only)" = page returned 403; fact comes from the search engine's excerpt, re-check before use. "community" = forum thread. Verified 2026-09-09.

## Job A — Campaign home / hub ("where am I, what's next")

### Roll20 — Game Details page

- Structure: the Details Page "is the first page new players see after accepting an invitation." Order: Game Icon, Game Name, "Launch Game", "Content" menu ("Chat Archive", "External Journal"), "Looking for Players", "Settings", then "Playing", "Next Game Will Be", "Game Description" (Markdown), Game Addons; roster on the right; private forum. https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only
- Disclosure: settings behind "Settings"; players only get "Leave Game" there. Language: "I'm ready, Create Game!" (copy dialog). Feedback: next-game time "is automatically converted to the viewer's local timezone." Shortcuts: "Copy Game" with per-element carry-over; Pro "Roll Back Game" to any of 7 daily saves. Same URL.
- Capture: https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only

### D&D Beyond — Campaign page

- Structure: joined characters as cards (DM sees backstory tabs, other players do not); "Game Log" and "Maps" top-right with the invite link "just under" them; "Create Encounters"; DM Notes for "public and private use". Guide, not official docs: https://www.thegamer.com/dungeons-dragons-how-to-use-dd-beyond-to-run-your-campaigns/
- Invite box copy (community): "Send players this invite link to have them join your campaign", with copy and reset-link buttons. https://www.dndbeyond.com/forums/d-d-beyond-general/general-discussion/76260-how-to-join-a-game-or-invite-players-to-join
- Order (community): "The public notes appear all the way at the bottom of the campaign page." https://www.dndbeyond.com/forums/d-d-beyond-general/bugs-support/88792-dm-notes-public-not-appearing-in-campaign
- Capture: https://www.dndbeyond.com/my-campaigns (login required)

### Kanka — Campaign dashboard

- Structure: "the default page members of a campaign see", initially "fairly empty"; Campaign Header (name, short description, image) "Always visible"; owner clicks "dashboard setup" → "add new widget": Entry List, Entry Preview, Calendar ("five previous and upcoming reminders"), Text Header, Random Entry. https://docs.kanka.io/en/latest/guides/dashboard.html
- Disclosure: premium campaigns get per-role dashboards (Action → Default → Player). Same URL. Feedback: calendar widget "shows the weather of the current day"; calendar detail loads after the page. https://blog.kanka.io/2022/05/23/1-28-work-it-dashboards-make-it-calendars/
- Shortcuts: "K" search, "N" quick creator, "]" sidebar, Ctrl+S save, Ctrl+Shift+S save and continue. https://docs.kanka.io/en/latest/advanced/keyboard-shortcuts.html

### Owlbear Rodeo — Profile page and room

- "The Game Master (GM) creates a room from their profile page"; a room "will have a name, background and a list of enabled extensions"; share the URL or click "Invite Players". (search excerpt only) https://docs.owlbear.rodeo/docs/rooms/
- Player first screen: the link "will put you in the waiting room where you can request to join." (search excerpt only) https://docs.owlbear.rodeo/docs/getting-started/

### World Anvil — Campaign Manager

- Tabs "Sessions" (each links its session report; "Start" opens the Digital Storyteller Screen) and "Protagonists (PCs)" to invite players, who need an account and a PC. (search excerpt only) https://www.worldanvil.com/learn/rpg/campaign-manager and https://www.worldanvil.com/learn/rpg/dsts

### Baldur's Gate 3 — Camp and Journal as framing devices

- Camp as hub: talk to/swap party members, "Traveller's Chest", Withers, Long Rest; fast travel to camp. Baldur's Gate 3 wiki: https://bg3.wiki/wiki/Camp
- Journal as "what's next": quest categories have "a sorting priority"; a quest carries "an objective-like title that portrays the end-goal". Baldur's Gate 3 modding docs: https://docs.baldursgate3.game/index.php?title=Journal_Structure_Overview
- Keys: "J" Journal, "M" Map, "N" Character Sheet, "I" Inventory, "Tab" Party View. Baldur's Gate 3 wiki: https://bg3.wiki/wiki/Controls
- State persistence: Patch 2 — "Quest categories and entries in the Journal will now remember whether you've expanded or collapsed them." Baldur's Gate 3 patch notes via Shacknews: https://www.shacknews.com/article/136870/baldurs-gate-3-patch-2-notes
- Narrated "previously on" recap on load: **unverified** — no official doc, wiki or patch note found; treat as absent from Baldur's Gate 3. The narrator acts "as BG3's dungeon master" in play: https://en.wikipedia.org/wiki/Baldur's_Gate_3

## Job B — Session notes and recap ("what happened last time")

### D&D Beyond — Game Log

- Reachable from the character sheet, "a campaign's main page, and within Encounters"; entries show the action, "the result of the roll plus any modifiers" and the dice set. https://www.dndbeyond.com/posts/939-share-your-dice-results-with-the-brand-new-game
- Disclosure: "Send To" dropdown at the top of the log sets the default for all rolls: "Everyone", "Self", "Dungeon Master"; per-roll override via right-click and the dice toolbar. https://www.dndbeyond.com/old-changelog/1013-keep-your-rolls-secret

### D&D Beyond — Campaign Notes (DM notes)

- Structure: "DM notes (Public)" and private DM notes plus a "Campaign description" (community labels). Public notes are visible to campaign members only. https://www.dndbeyond.com/forums/d-d-beyond-general/bugs-support/88792-dm-notes-public-not-appearing-in-campaign (community)
- Use (community): public = table rules and recaps; private = secrets; spoiler tags to shorten; several call it "too unwieldy to manage" and move to Google Docs/OneNote/Discord. https://www.dndbeyond.com/forums/d-d-beyond-general/general-discussion/116008-campaign-notes (community)

### Roll20 — Chat Archive and External Journal

- "The Chat Archive will open a new window that displays the entire chat history"; "Hide Whispers" button; players see only whispers sent to them; "GM Rolls are only visible to the GM." https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only
- Roll privacy: "/gmroll shows the result to both the GM and the roller"; "/sr" and "/ssr" go only to the GM; 3D dice are suppressed "to avoid giving away that a hidden roll took place." https://help.roll20.net/hc/en-us/articles/360039675093-Text-Chat
- Failure guard: "Clear Chat Archive… permanently deletes the entire archived chat history". Game Details URL above.

### Foundry VTT — Journal text pages

- Entry = container of Pages (Text, Image, Video, PDF); text auto-saves every 60 s, collaborative. Shortcuts: Ctrl+B/I/U, Ctrl+Shift+8/9 lists, Ctrl+Shift+1–6 headings; drag a document to link, or `@UUID[...]{label}`. https://foundryvtt.com/article/journal/

### Kanka — Journals

- Free-form entries with an "author" field so a character gives "their point of view on something happening in a session". https://docs.kanka.io/en/latest/entries/journals.html Bulk: "Editing & tagging", "Change permissions", "Copy to campaign", "Print", "Remove". https://docs.kanka.io/en/latest/guides/bulk.html

### World Anvil — Session reports

- "Session reports can be found linked from each session in the 'Sessions' tab of the campaign manager." (search excerpt only) https://www.worldanvil.com/learn/rpg/campaign-manager

### Owlbear Rodeo — Journal! extension

- "Party" tab is "saved to the GM's data, but is viewable and editable by everyone in the room"; "Private" tab is per player; "up to four slots" each; local storage by default. https://extensions.owlbear.rodeo/journal

### Corroboration — Obsidian / Notion

- Sly Flourish: one file per session, headers for the eight Lazy DM steps, "Session Notes" folder. https://slyflourish.com/obsidian.html
- Vaultorial: session note = recap, scene log, clues handed out, "next time" block that becomes the prep list. https://vaultorial.com/dnd-campaign-vault/
- Player-side Obsidian: embed last session's summary by block reference (search excerpt). https://nicolevanderhoeven.com/blog/20210809-dnd-obsidian-player/
- Notion templates: https://www.notion.com/templates/dnd-session-notes ; https://slyflourish.com/lazy_dnd_with_notion.html

## Job C — Scheduling the next session, availability polls, shared calendar

### Roll20 — "Next Game Will Be" and Schedule prompt

- One date/time field, "automatically converted to the viewer's local timezone"; 12-hour picker. https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only
- Micro-prompt (staff post): a "Schedule Next Game" prompt appears "on the Game Details page an hour after your last scheduled game time" and pre-suggests a date from the last game and the LFG frequency. https://app.roll20.net/forum/post/2456566/mini-update-9-slash-25-schedule-next-game/
- Limit (community): "can only currently show 1 upcoming game time"; workaround is a sticky forum post. https://app.roll20.net/forum/post/4277521/multiple-game-dates

### Apollo (Discord bot) — event with RSVP

- Flow: "/event" → "Apollo will then DM you a list of questions" → link to the event → "RSVP… by clicking one of the event buttons". Required: name, start time "(including time zone)"; optional: description, duration, attendee limit, recurrence, roles to mention. "Event creation occurs in a direct message." https://docs.apollo.fyi/ ; https://docs.apollo.fyi/creating_events
- RSVP states: defaults "Accepted, Declined, and Tentative"; "only the Accepted option indicates attendance" and triggers reminders; capacity per option; up to 20 options; presets via "/signup_presets default". https://apollo.fyi/blog/custom-signup-options
- Permissions: "anyone can create events", edit/delete own only; "/settings role". Same URL.

### Doodle — Group Poll

- Flow: "Group Poll" tile → title, description, location → slots in Week/Month view → optional deadline, reminders, hidden participant list (paid) → "Create and share" → "Copy link". https://help.doodle.com/en/articles/9457353-how-do-i-create-a-group-poll
- Close: organiser clicks "Book it"; participants "automatically receive an email with all the event information". https://help.doodle.com/en/articles/9823082-introduction-to-group-poll

### When2meet — availability grid

- Flow: create event (name, dates, time window, zone) → share URL → participants type a name (no account) and drag on the grid; overlap accumulates; no save button. https://www.when2meet.com/ ; community guides: https://docs.codeday.org/mentor-training/when2meet-guide.html ; https://www.usecarly.com/blog/how-to-use-when2meet/

## Job D — Notes and lore: NPCs, places, factions; secret vs player-visible

### Roll20 — Journal, Characters, Handouts

- Default: "The GM is the only person that can see a Handout by default." Fields: "In Player's Journals (GM Only)" (or "All Players"); "Can Be Edited By (GM Only)"; "Description & Notes" (player-visible) vs "GM Notes (GM Only)", which "Only a GM can edit and view… regardless of other settings." https://help.roll20.net/hc/en-us/articles/360039675133-Journal
- Characters: view-only players see "only the Name, Avatar, and… Bio & Info"; "GM Notes Field" is GM-only. Same URL.
- Disclosure: folders with only GM items are hidden from players; "Archive" removes items from the list; "Player View" shows "the Journal exactly as that player sees it."
- Language: default handout name "Mysterious Note"; "+ Character", "+ Handout", "Duplicate Handout" → "Copy of (name)", "Archive Handout", "Delete Handout" (confirm). Shortcuts: drag a handout onto a player name = grant + open instantly; Tags; Journal Command Buttons; double-click minimises. Same URL.
- Capture: https://help.roll20.net/hc/en-us/articles/360039675133-Journal

### Foundry VTT — Journal ownership and secret blocks

- Ownership: "None" (default for non-creators), "Limited" ("see the map pin… but will not see it in the sidebar"), "Observer", "Owner". https://foundryvtt.com/article/journal/ ; user roles: https://foundryvtt.com/article/users/
- Secret text inside a page: "Block" → "Secret"; visible only to GM/Owner; a reveal button toggles it. Journal URL above.
- Context menu: "Configure Permission", "Duplicate", "Export Data", "Import Data". Same URL.

### Kanka — private entries, visibility, posts

- Roles Admin/Players/Public. "If that field [privacy] is checked, the entry will only be visible to members of the campaign's admin role." Players role has no permissions by default: "seeing the campaign, but not seeing anything in it." https://docs.kanka.io/en/latest/features/permissions.html
- Element visibility: "All", "Admins", "Only me", "Only me & Admins", "Members of the campaign"; applies to relations, reminders, timeline elements, inventory, map markers. https://docs.kanka.io/en/latest/advanced/visibility.html
- Three secret levels: private entries ("hides related connections"), posts with visibility, element visibility. https://docs.kanka.io/en/latest/guides/secrets.html

### World Anvil — Secrets and Subscriber groups

- Secrets are "chunks of content you create separately and embed into articles", visible per subscriber group; "different subscriber groups per party". (search excerpt only) https://www.worldanvil.com/learn/beginner-tutorials/get-started-secrets ; https://www.worldanvil.com/learn/access-rights/subscribers
- Third-party detail: "+ Secret" in the Secrets panel; embed via clipboard icon; readers without access "see no blank space"; visibility controls sit in presentation view, "not edit mode — a common confusion point"; reveal live by adding a group. https://loreteller.com/learn/world-anvil-secrets-guide/

### Owlbear Rodeo — GM Vault, notes

- GM Vault: "keep content GM-only by default"; toggle visibility with the eye icon per page or folder; "Players don't need a token". https://extensions.owlbear.rodeo/gm-vault
- Core notes are an image type with rich text; can be hidden/locked; edit by double-click; player visibility rules not documented. https://blog.owlbear.rodeo/owlbear-rodeo-2-0-dev-log-5/

## Job E — Handouts, images, letters shown to players; reveal / revoke

### Roll20 — "Show To Players"

- Shows the dialog "on the screens of any players who have permission to View"; if none, a prompt: "Clicking Show to Everyone will insert All Players into the In Player's Journals field." https://help.roll20.net/hc/en-us/articles/360039675133-Journal
- Reveal = permission side effect; revoke = remove names from "In Player's Journals" (or "Archive Handout"). Same URL.
- Capture: https://help.roll20.net/hc/en-us/articles/360039675133-Journal

### Foundry VTT — "Show Players"

- "Show Players" shows an entry "to all players or selected individuals… bringing it to the forefront of their screen"; in multi-page view "right-click individual pages for selective sharing"; Image pages hold "picture hand-outs"; Observer can "toggle between Image view and Text view". https://foundryvtt.com/article/journal/
- Community modules add one-off image push ("Show to Players… no journal entry needed"): https://foundryvtt.com/packages/quick-scenes

### Owlbear Rodeo — GM Vault

- Handouts: "click images to view full screen and Show to players"; eye icon reverts. https://extensions.owlbear.rodeo/gm-vault

### Simple Calendar (Foundry) — note "Show Players"

- Right-click a note → "Show Players": "functions the exact same as the Show Players button in the header of a Journal Entry… regardless of if they can see it or not." https://simplecalendar.info/docs/using-sc/notes/

### World Anvil — reveal by group

- Reveal = add a subscriber group to a secret; content becomes visible "across all embedded locations"; removal is the inverse. https://loreteller.com/learn/world-anvil-secrets-guide/ (third-party)

## Job F — In-world calendar, date, weather

### Simple Calendar (Foundry module)

- First screen: month grid, Month/Year, season name, per-day note counts, moon phases, clock; buttons "Calendars" (if 2+), notes, "Search Notes", "Today", "Configuration" ("Players will see a limited selection"). https://simplecalendar.info/docs/using-sc/calendar-view/
- Date change (GM or granted roles): "« / »" ±5, "‹ / ›" ±1 of a chosen unit (Second/Round/Minutes/Hour/Day/Month/Year); "Dawn, Midday, Dusk, Midnight"; "Set Date" appears when a non-current day is selected; right-click day → set current. Compact "Quick Increment" 1r/1m/5m/15m/1h; Shift multiplies, Ctrl subtracts. https://simplecalendar.info/docs/using-sc/changing-date-time/
- Notes: journal entries in a hidden folder; list shows title, bell, time or "all day", author ("System" for predefined), categories, GM-only "Player Visible" icon with a tooltip listing who can see it. Right-click: "Remind Me / Don't Remind Me", "Show Players", "Edit", "Delete". Players may add notes if permitted. https://simplecalendar.info/docs/using-sc/notes/
- Feedback: right-click day shows sunrise/sunset; reminders fire when game time passes the note. Weather via companion module https://foundryvtt.com/packages/simple-weather
- Capture: https://simplecalendar.info/docs/using-sc/calendar-view/

### Seasons & Stars (Foundry v13 module)

- "Quick Time Buttons" with live preview; GM-only time changes; plus button on a date creates a note. https://github.com/rayners/fvtt-seasons-and-stars Core v13: `CalendarData#add` https://foundryvtt.com/releases/13.341

### Fantasy Calendar (app.fantasy-calendar.com)

- Events: hover a day → "Add Event"; fields Name, Description, Category, Conditions; visibility "Hide entirely", "Hide from players" (owner still sees it, marked cross-checked), "Show when printing". https://helpdocs.fantasy-calendar.com/topic/events/
- Roles: Owner; Co-Owner ("can modify the current date and time"); Player (one-time events, may hide them, but owners still see; limited categories); Observer (view, comment). Invites by email, pending invites cancellable. https://helpdocs.fantasy-calendar.com/topic/user_management/
- Guest settings: "Enable previewing dates in calendar", "Show only up to current day", "Hide future weather from guest viewers", "Hide temperature…", "Hide all events from guest viewers", "Hide all moons…", "Make calendar private". https://helpdocs.fantasy-calendar.com/topic/settings/
- Weather: seeded pseudo-random, requires seasons, same seed = same weather across calendars; "Cinematic temperature description". https://helpdocs.fantasy-calendar.com/topic/weather/

### Kanka — Calendars and reminders

- "Advancing date" option "advances the day by one every night at 00:00UTC"; date format tokens `d M, y s`; reminders "only displayed over the span of maximum 2 months"; parent calendars propagate reminders. https://docs.kanka.io/en/latest/entries/calendars.html
- Reminders link any entry to a calendar with the visibility dropdown; moon-phase recurrence is "excluded from the dashboard". https://docs.kanka.io/en/latest/features/reminders.html ; https://blog.kanka.io/2021/05/13/kanka-1-9-calendars-reminders-moon-stuff/

### World Anvil — Calendars and Timelines

- "+Calendar" under Advanced Tools; "Copy Calendar BBCode"; `[calendar:1234|2025]` shows a given year; "Calendars are not timelines… A calendar represents a cycle, a timeline represents a line." (search excerpt only) https://www.worldanvil.com/learn/calendars/calendars
- Timelines: eras and events; "Private events are possible in a public timeline"; subscriber groups per timeline. (search excerpt only) https://www.worldanvil.com/learn/timelines/timelines

### Donjon — Fantasy Calendar generator

- Inputs "Days in Year", "Number of Months", "Days in Week", "Number of Moons" (max 13), "Celestial Events?"; outputs a year view and Moons; "Save this calendar to file" / "Restore a calendar from file". Weather/events: **unverified**. https://donjon.bin.sh/fantasy/calendar/

### Owlbear Rodeo — extensions

- "Calendar!", "Calendar of Harptos", "OwlClock" listed on the official extension store. https://extensions.owlbear.rodeo/

## Job G — Party invitation / join and member roles

- "A person can join a Campaign only if they are invited… via a link." DM: "Copy Link" "under the Campaign Name." Player lands on "Join a Campaign": "CREATE A CHARACTER", "CREATE FROM PREMADE CHARACTERS", claim a DM-made character, or pick from "My Characters", then "JOIN WITH THIS CHARACTER". "You may need to refresh the page"; a second character needs the link again. https://dndbeyond-support.wizards.com/hc/en-us/articles/14025808350612-Joining-a-D-D-Beyond-Campaign

- Roles: "Creator", "Player", "GM or Co-GM". "Invite Players" → email + "Invite as" → "Send Invite" → "Pending Invitations"; or "Player Join Link" (unlimited, "changes whenever a Player is kicked"); "Generate GM Link" (single-use, 48 h). ### World Anvil

- Players are invited via "Protagonists (PCs)"; they need an account and a player character. (search excerpt only) https://www.worldanvil.com/learn/rpg/campaign-manager

## Dominant pattern per job

- **A. Hub.** Roster + one primary action + invite link + next-session date on the first screen; settings behind a menu. Proof: Roll20 Game Details ("first page new players see", "Launch Game", "Next Game Will Be") https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only ; D&D Beyond campaign page ("Copy Link", Game Log, character cards) https://dndbeyond-support.wizards.com/hc/en-us/articles/14025808350612-Joining-a-D-D-Beyond-Campaign ; Kanka dashboard (header always visible, calendar widget) https://docs.kanka.io/en/latest/guides/dashboard.html. Rule: opening a campaign shows party, primary action, invite link and next date without scrolling.
- **B. Recap.** An automatic log (rolls/chat) plus a separate written recap per session, reachable from the hub. Proof: Roll20 Chat Archive https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only ; D&D Beyond Game Log https://www.dndbeyond.com/posts/939-share-your-dice-results-with-the-brand-new-game ; World Anvil session reports per session https://www.worldanvil.com/learn/rpg/campaign-manager. Rule: each session has an auto log and a written recap; the latest recap is one step from the hub.
- **C. Scheduling.** One proposed time in the viewer's local zone, answered in one tap with three states. Proof: Roll20 auto-converted "Next Game Will Be" https://help.roll20.net/hc/en-us/articles/29620064514071-Game-Details-Page-GM-Only ; Apollo "Accepted, Declined, and Tentative" https://apollo.fyi/blog/custom-signup-options ; Doodle vote → "Book it" https://help.doodle.com/en/articles/9823082-introduction-to-group-poll. Rule: a slot renders in local time, takes Accept/Tentative/Decline in one tap, and reminds before start.
- **D. Notes and lore.** GM-only by default, revealed per element, and hidden content leaves no placeholder. Proof: Roll20 "only person that can see a Handout by default" https://help.roll20.net/hc/en-us/articles/360039675133-Journal ; Foundry ownership "None" + Secret blocks https://foundryvtt.com/article/journal/ ; Kanka visibility dropdown https://docs.kanka.io/en/latest/advanced/visibility.html ; World Anvil secrets "no blank space" https://loreteller.com/learn/world-anvil-secrets-guide/. Rule: notes default private, reveal per element in place, and a "view as player" check exists.
- **E. Handouts.** "Show to players" displays now and grants access as a side effect; revoke is a separate toggle. Proof: Roll20 "Show to Everyone will insert All Players" https://help.roll20.net/hc/en-us/articles/360039675133-Journal ; Foundry "Show Players… to the forefront of their screen" https://foundryvtt.com/article/journal/ ; Owlbear GM Vault eye toggle https://extensions.owlbear.rodeo/gm-vault. Rule: one action pushes and records access; access persists until toggled off.
- **F. Calendar.** GM-only time advance by fixed steps plus "set this day as current"; per-event visibility; hidden events stay visible to the GM, flagged. Proof: Simple Calendar https://simplecalendar.info/docs/using-sc/changing-date-time/ ; Fantasy Calendar "Hide from players" https://helpdocs.fantasy-calendar.com/topic/events/ ; Kanka "Advancing date" https://docs.kanka.io/en/latest/entries/calendars.html. Rule: players read current date and visible events; GM advances by steps and sees hidden events flagged.
- **G. Join.** Invite is a link carrying a role; the player picks or creates a character on join; removal rotates the link. Proof: D&D Beyond "Join a Campaign" https://dndbeyond-support.wizards.com/hc/en-us/articles/14025808350612-Joining-a-D-D-Beyond-Campaign ; Roll20 link "changes whenever a Player is kicked" https://help.roll20.net/hc/en-us/articles/29620515876375-Invite-Promote-and-Manage-Players ; Kanka invite "Role" + "Expires after" https://docs.kanka.io/en/latest/features/campaigns/members.html. Rule: a join link fixes the role, lands on a character-choice step, and is rotated on removal.

## Documented failures — do not copy
