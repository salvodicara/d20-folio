# Rules coverage map — 2026-10-13

Every SRD 5.2.1 rules element against today's `main`: auto = the engine computes it or one tap makes
every consequence flow; 1-tap = one dedicated tap records it; manual = no dedicated support, but
representable by hand (HP edit, condition, override, custom tracker, notes); **impossible** = cannot
be represented at all. Catalogue rows give counts auto / 1-tap / manual / impossible, from scripts
over `catalogueActivities()` and the data modules. A closed gap updates its row in the same PR.
