# Rules coverage map — 2026-10-25

Every SRD 5.2.1 rules element against today's `main`. Class = what the **engine** supports: auto =
applied with no input; 1-tap = one declaration by the player or DM applies it; reference = text
shown, no mechanics; manual = tracked by hand (HP edit, condition, override, tracker, notes);
**impossible** = cannot be represented. **UI pending: `<seam>`** in the Gap column = the pure core
is merged and tested but no screen calls it yet (the old UI is frozen), so a player cannot use that
part today. Catalogue rows give counts auto / 1-tap / reference / impossible; a `rules-coverage-*`
test recounts each row that cites one. Re-audited row by row against code and tests on 2026-10-25;
a closed gap updates its row in the same PR.
