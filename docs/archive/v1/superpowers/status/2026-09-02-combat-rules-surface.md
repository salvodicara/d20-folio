# d20 Folio — Combat Procedure Rules Surface (SRD 5.2.1)

Yardstick for the combat-architecture audit. Every row is one atomic rule/procedure item of D&D 2024
combat **procedure** (rules of play, not per-entry spell/feature content) that a total-automation
engine must model for every combatant (PCs, monsters, NPCs, summons, companions, mounts), under the
product constraints:

- **(a) Dice** — _reversed on 2026-09-03_ (constitution §2.2, ADR-0010): every die result is a
  `roll` action, rolled in-app through the dice seam or entered from real dice. The audit below
  was written under the original "no dice generation" constraint.
- **(b) No geometry** — no coordinates, grids, maps, line-of-sight computation. The app owns
  **declared relational facts** only (adjacency, range band, DM-declared cover, marks, aura
  membership, engagement, visibility) with derivable consequences computed automatically.
- **(c) Override-first** — every derived value auto-computes and is overridable.

## Source and citation method

- Primary source: **SRD 5.2.1** (CC-BY-4.0). The official PDF URL
  (`media.dndbeyond.com/.../SRD_CC_v5.2.1.pdf`) returned an S3 `AccessDenied` from this
  environment, so the text was verified against two sources that carry the same wording:
  1. A CC-BY-4.0 Markdown conversion of SRD 5.2.1 (`github.com/downfallx/dnd-5e-srd-markdown`,
     shallow-cloned 2026-09-02; files `playing-the-game.md`, `rules-glossary.md`, `spells.md`,
     `equipment.md`, `magic-items.md`, `monsters.md`, `monsters-A-Z.md`, `classes.md`, `feats.md`).
  2. D&D Beyond "Free Rules (2024)" pages (`/sources/dnd/free-rules/{playing-the-game,
rules-glossary, spells, equipment, feats}`), which reproduce the same 2024 text.
- Citation shorthand used in the tables:
  - `PtG > …` = SRD 5.2.1 chapter "Playing the Game", section path.
  - `RG: "Entry"` = SRD 5.2.1 "Rules Glossary" entry name (bracketed tag as printed, e.g. `[Action]`,
    `[Condition]`, `[Area of Effect]`, `[Hazard]`).
  - `Spells > …` = chapter "Spells"; `Equip > …` = "Equipment"; `MI > …` = "Magic Items";
    `Monsters > …` = "Monsters" chapter (stat-block rules); `Monsters A–Z: <name> / <trait>` =
    wording of a trait/action inside a specific SRD stat block; `Classes > …`, `Feats > …`.
- Every citation below was checked verbatim against the sources above unless marked
  **(citation from memory — verify)** or **(NOT in SRD 5.2.1)**. Nothing is invented; where the SRD
  is silent (e.g., joining combat mid-encounter) the row says so and the item is a ruling.

## Reading the columns

| Column                   | Meaning                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| ID                       | Stable item id, `AREA-nn`.                                                                                                            |
| Item                     | The atomic rule/procedure.                                                                                                            |
| SRD 5.2.1 citation       | Section / glossary entry.                                                                                                             |
| Table MUST supply        | Physical die results, declared facts, or rulings the app cannot produce.                                                              |
| Engine derives / applies | What auto-computes once inputs exist (all overridable per constraint (c)).                                                            |
| Scope                    | `self` (one combatant's own state) / `other` (one other creature) / `multi` (several creatures) / `encounter` (encounter-wide state). |
| No-geometry boundary     | Which spatial fact must be a **declared fact with a default + override**, and what is derivable from it.                              |

Shorthand: **DF** = declared fact (default + override); **DR** = die result input; **RL** = ruling
input (DM/player decision the rules delegate). **PB** = Proficiency Bonus. "Adjacent" = the declared
relation "within 5 feet of". "Engaged" = declared "within reach of a hostile creature".

## (b) Structurally table-only vs fully derivable

### B1. Structurally table-only even under total automation

These require a **physical die**, a **geometry fact**, or a **ruling** the rules delegate to a person.
The engine can prompt, validate, and apply consequences, but can never originate the value.

**Physical die inputs (constraint a)**

- Every d20: Initiative (STR-03/04/13), attack rolls incl. raw face for nat 1/20 (ATK-02/03), all
  saving throws incl. Concentration (SAV-01, CON-04) and Death Saves incl. raw face (HP-14/15),
  ability checks (Hide, Search, Study, Influence, Escape, Medicine, Athletics/Acrobatics fall
  check) (ACT-19/20/24/25, CND-17, HP-17, ACT-11), the second d20 whenever net Advantage/Disadvantage
  applies (ATK-05), rerolls (ATK-06).
- Every damage/healing die: weapon/spell/trait damage, crit-doubled dice (ATK-12/13/15),
  Graze is _not_ a roll (derivable), Hit Dice on Short Rest (HP-20), Second Wind/potions/Lay On
  Hands amounts where dice are involved (ACT-34, HP-09), fall damage (ACT-11), Burning (HP-23),
  mark riders (REL-02/03), Sneak Attack dice (ATK-28), Deflect Attacks reduction (ATK-29).
- Monster **Recharge d6** at the start of the monster's turn (MON-06); optional rolled monster HP
  (MON-01); 1d4 hours to wake when Stable (HP-17/RST-10).

**Geometry facts (constraint b) — declared with default + override**

- Adjacency / "within 5 ft" (MOV-02) for: Unarmed Strike, Help (attack), Pack Tactics, Sneak Attack
  ally, ranged-in-melee, Prone Adv/Disadv, Paralyzed/Unconscious auto-crit, Cleave, potions,
  mounting, spirit/aura 5-ft triggers.
- Range band (MOV-03): ranged normal/long/beyond, spell range, Counterspell 60 ft, familiar 100 ft,
  command ranges, "within reach" for reach-10 attacks.
- Cover degree (MOV-04, ATK-07, SPL-11).
- Visibility per ordered pair when not derivable from conditions/senses (MOV-05, ATK-08, CND-05
  line of sight, ACT-17 "can see attacker", ACT-28 "creature you can see", SPL-16/19).
- Area-of-effect membership for every Cone/Cube/Cylinder/Emanation/Line/Sphere and every persistent
  area/aura/object area (SPL-12, REL-05, REL-09, ITM-13, MON-03).
- Engagement transitions: "leaves reach", "enters area/aura", "distance exceeds grapple range"
  (MOV-07/08, ACT-28, CND-06).
- Movement facts: distance moved, mode, difficult terrain, height when flying, jump type
  (ACT-05/07/08/09/10/11, MOV-06); sharing a space at end of turn (ACT-13); position after forced
  movement/teleport (MOV-08, SPL-20).
- Environmental flags: underwater, in lair, in Silence, in darkness/fog, mounted (MOV-12).
- Hide preconditions: Heavily Obscured / behind ¾ or Total cover / out of every enemy's line of
  sight (ACT-19).

**Rulings (the rules delegate to a person)**

- Surprise per combatant (STR-05); Initiative tie order (STR-09); who joins/leaves and when combat
  ends (STR-13/14); simultaneous-effect ordering (STR-17); identical-monster grouping (STR-04);
  roll-vs-score and average-vs-dice preferences (STR-07, MON-04).
- Influence willing/unwilling/hesitant and the skill used (ACT-20); whether a free interaction
  needs an action (ACT-04); readied-trigger occurrence and perceivability (ACT-22); "assistance
  possible" for Help (ACT-18); slippery/rough-water checks (ACT-09).
- Legendary Resistance spend (SAV-08); choosing to fail a save (SAV-01); THP keep/replace (HP-07);
  knock-out choice (ATK-30); treat-monster-like-a-character (HP-10/MON-19); Cleave/Push/Slow/Topple
  "you can" choices (ATK-21..26); reaction choices at every interrupt window (SPL-17).
- Invalid-target determinations not derivable from data (SAV-09); improvised-weapon type/equivalence
  (ATK-16); Concentration/side designations for NPCs (REL-01); dawn/dusk occurrence for item
  recharge (ITM-06); whether a Lair-Action homebrew is in force (MON-10).

### B2. Fully derivable once declared facts and die results are present

- Initiative totals, modifiers, Alert PB, Adv/Disadv from Incapacitated/Invisible, order sorting,
  fixed order across rounds, mount/summon Initiative placement (STR-03/06/08/10/11/12).
- Whole action economy: slot counts, Bonus-Action availability from Grants, Reaction reset at own
  turn start, Reactive override, Incapacitated gates, free-interaction counter, Dash/Disengage/Dodge
  effects, Ready storage/expiry, Extra Attack counts, Light/Nick/Two-Weapon rules, one-slot-per-turn
  guard, Action Surge exclusion (ACT-01..03, 12, 14..17, 21..23, 29..35).
- Movement arithmetic: effective Speed (Exhaustion, Slow, Speed-0 conditions, special-speed
  coupling), cost multipliers, stand-up cost, Dash increase, jump maxima, fall damage dice count and
  Prone (ACT-05..12).
- Attack resolution: attack modifiers, AC, proficiency, net Adv/Disadv from all sources given DFs,
  cover bonuses, unseen rules, range Disadvantage, ranged-in-melee, nat 1/20, crit dice doubling,
  damage modifiers and clamps, ammunition/loading, mastery consequences (Cleave once/turn, Graze
  damage, Push size gate, Sap/Slow/Vex tokens, Topple DC), knock-out branch, underwater modifiers,
  damage threshold (ATK-02..27, 30..32).
- Saves: DCs, modifiers, cover, Dodge/Restrained/Magic Resistance/Exhaustion, auto-fail conditions,
  half-damage mapping, Evasion, per-target fan-out from one damage roll, repeated-save scheduling,
  Legendary Resistance accounting (SAV-02..08).
- Damage pipeline: ordered adjustments → Resistance → Vulnerability, no-stacking, immunity, flat
  reductions, THP absorption/expiry/no-stack, healing cap, 0-HP transitions, massive damage, monster
  death, death-save counters and 1/20 rules, damage-at-0 failures (crit-aware), Stable/dying/dead
  FSM, Exhaustion penalties and death at 6, Regeneration, Relentless-type interrupts, Bloodied flag
  (HP-01..23).
- Conditions: every mechanical consequence of all 15 conditions, per-source overlap semantics,
  Incapacitated cascade, escape DC, duration scheduling, shape-shift carry-over (CND-00..19).
- Concentration: single slot, break on new Concentration/Incapacitated/0 HP/death, per-instance DC,
  voluntary end, max duration, dependent cleanup, readied/multi-turn casting semantics, item-cast
  Concentration (CON-01..11).
- Spellcasting: slots/levels/upcasting/rituals, casting-time routing, components from hands and
  Speechless/Silence membership, armor training, Touch = adjacency, durations, target validation,
  Total-cover block, area fan-out over declared membership, DCs/attack bonuses, same-spell
  non-stacking, Shield retroactive AC, Counterspell cancel + slot refund, phased interrupt windows,
  teleport OA suppression (SPL-01..21).
- Relations: side model, mark links with per-hit riders and retarget prompts, aura membership
  triggers, controller links and default Dodge behaviour, familiar touch delivery, steed/animated
  Initiative placement, Dominate Reaction coupling, mounted rules and fall-off saves, grapple/shove
  as saves, Pack Tactics, swarm healing block, Split spawning, pair-scoped relation table
  (REL-01..18).
- Monster execution: stat-block model, PB from CR, attack/save/damage notation branches,
  Multiattack composition, Recharge/X-Day/rest counters, Legendary Action windows and resets,
  trait hooks (Regeneration/Rampage/Bloodied Frenzy/Split/Flyby/Reactive/Magic Resistance),
  spellcasting entries, in-lair numbers (MON-01..24 except the d6 and rulings above).
- Rests: benefits, interruptions, partial credit, HD arithmetic, reset policies, attunement at
  rests, all duration classes incl. 1 minute = 10 rounds and "its next turn" keys (RST-01..14).
- Items: attunement slots/prereqs/ending on death, slot/pair rules, activation economy, consumable
  decrement, item-cast spell derivation, charge ledgers with reset policy, equip/unequip and free-hand
  ledger, shield/armor rules, improvised classification, object-area triggers over declared
  membership, magic bonuses (ITM-01..15).
- Movement/relations: reach derivation, engagement default from adjacency + reach, visibility
  defaults from conditions/senses, forced-movement default consequences (adjacency cleared, grapple
  ended, OA suppressed), size gates (MOV-01, 05 defaults, 07 defaults, 08, 09, 11).
