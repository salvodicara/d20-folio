# Landscape research: teardown targets for a D&D 5e (2024) digital table

Researched 2026-09-12 via web search. Product vision under test: BG3-grade automation at the table
(hotbar, automatic resolution, initiative, reactions, dice, token map) + D&D Beyond-grade character
tooling (sheet, builder, level-up, inventory, loot transfer, party inventory, DM tools, homebrew)

- session notes/recap, scheduling, chronicle, NPCs/places, handouts. Offline-first PWA, EN/IT,
  remote and physical table. No AI narrator, no chat/voice, no 3D.

Status flags: **[verified 2026]** = confirmed by a 2026-dated source; **[2025]** = latest evidence
is 2025; **[unverified]** = could not confirm current status in this pass.

**Corrections (2026-09-13, after the Codex review, finding 08).** Encounter+ verified and promoted
(row and priority list); "the only 2024-rules implementation" softened to "the first shipped one
found", with the studio's own statement on the cost of two rulesets. Marked in the text.

## 2. Most-requested features and top complaints, 2025–2026

**D&D Beyond** (forum feedback threads + roadmap AMA context)

- Sheet bugs after 2024 rollout: feats not addable, spells not displaying, subclass features missing or wrong; "2024-compatible" marketplace content not working with 2024 classes. https://www.dndbeyond.com/forums/d-d-beyond-general/d-d-beyond-feedback/233886-overpromise-underdeliver-the-state-of-d-d-beyond
- Search is "frustratingly bad"; a semantic search with 5e/5.5e filtering is on the 2026 roadmap. https://www.dndbeyond.com/posts/2223-mid-year-update-d-d-beyonds-2026-development
- Demand to **hide/separate 2024 vs 2014 content** (legacy toggle). https://www.dndbeyond.com/forums/d-d-beyond-general/d-d-beyond-feedback/219284-the-future-of-d-d-beyond
- Maps: less intuitive than competitors, handouts removed, prep tools missing (now roadmap: scene prep, custom uploads); promised 2025 features slipped to 2026; Sigil collapse eroded trust.
- Pricing: à-la-carte purchases removed; homebrew tooling still weak (improvements "promised later"); mobile app for in-person play not before early 2027.
- **Takeaways to copy/avoid:** ship a sheet that is correct for 2024 rules first; edition filter everywhere; homebrew as first-class; in-person mode on mobile now, not 2027.

**Roll20**

- Bugs/regressions after releases and "losing people because of the bugs" threads; users migrating to Foundry. https://app.roll20.net/forum/post/9949151/roll20-is-losing-people-because-of-the-bugs-in-the-last-month
- Free tier limits: dynamic lighting and API behind Pro; custom sheets require Pro; legacy performance (fixed by Jumpgate: 1/2 CPU, 1/3 memory). https://pages.roll20.net/redesign
- **Takeaways:** performance budget as a feature; no feature paywalls that block the table; regression tests on the sheet.

**Foundry VTT**

- Front-loaded setup (1–2 h), self-hosting/networking, "easy to lose an evening to configuration". https://advancedrpgs.com/foundry-vtt-review-best-features-pain-points-and-who-should-buy-it/
- Module fragility: 5e system breaking changes each major (v3→v4→v5→v6 activities) exhaust module authors; Midi-QOL/DAE version-lock chains. https://foundryvtt.com/packages/midi-qol
- Window stacking and permission/token dialog quirks; heavy scenes punish weak hardware; weak touch/tablet support (TouchVTT module; not Steam Deck verified). https://www.foundryvtt-hub.com/package/touch-vtt/
- v15 plan explicitly prioritizes "long-term stability, minimal breaking changes" — the community asked for it. https://foundryvtt.com/article/year-in-review-2026/
- **Takeaways:** zero-setup, one-app automation (no module stack); touch-first; stable data schema with migrations.

**Cross-cutting requests seen across all three:** true offline/in-person mode; a sheet + map + dice on one screen ("reduce tab switching" is literally DDB's 2026 wording); reliable 2024-rules automation; loot/party inventory; session prep pinned to the map; printable sheets.

## Teardown priority (study in this order)

1. **Baldur's Gate 3** — the owner's stated bar for hotbar, reaction prompts, initiative strip, dice screen, party inventory, level-up; the widest public UI corpus (Game UI Database, XAML docs, UX deep dives).
2. **Solasta: Crown of the Magister (+ Solasta II EA)** — the most rules-faithful 5e engine; reaction prompts, advantage/disadvantage sourcing, combat log; Solasta II is the first shipped 2024-rules implementation found (the studio switched in June 2025 and states that supporting both rulesets "would take us an incredible amount of time … every monster, every class and subclass would need two different versions", https://www.solasta-game.com/news/208-solasta-ii-is-switching-to-the-2024-ruleset). _Corrected 2026-09-13: "the only" was an over-claim._
3. **Foundry dnd5e system (Activities, Active Effects V2) + Midi-QOL/DAE presets** — the published mechanics-as-data model and the three-level automation precedent; source code is readable.
4. **D&D Beyond** (sheet, Quickbuilder, Maps condition sync, 2026 roadmap) — the character-side parity target and the list of pains to avoid (search, edition filter, homebrew, mobile).
5. **Shard Tabletop** — the consolidated action block (actions/bonus/reactions/features + active effects) and self-serve content editor; closest existing "sheet + automation" hybrid for 5e 2024.
6. **Owlbear Rodeo 2** — onboarding in 30 s, touch/mobile canvas, extension panels over a shared scene; the map/fog UX floor for the physical table.
7. **Roll20 Jumpgate redesign** — performance budget, undo/redo, page folders, Map Pins (secret DM notes), multiple sheet editions per campaign.
8. **Pathbuilder 2e** — plan-ahead progression and one-tap level-up; the mobile builder UX standard.
9. **Pathfinder: WotR / Rogue Trader combat log** — roll-breakdown-with-provenance UI, and level-up wizard failure modes to avoid.
10. **Fire Emblem combat forecast + Into the Breach telegraphing + Tactical Breach Wizards undo** — a trio for "preview before commit, undo after": exact fit for propose-and-confirm automation.
11. **Avrae + Improved Initiative** — minimal, correct combat-state models (initiative, HP, conditions with durations, resistances) that survive without a map.
12. **LegendKeeper + Kanka (+ NWN DM client)** — offline-capable campaign wiki, entity relations, adventure log/recap, secrets/handouts; the DM-client philosophy "an extension of the player interface".

Deferred/low priority: Fantasy Grounds (deep but dated UI; study effect strings only), Alchemy (scene mood), TaleSpire/TTS/Sigil (3D, off-vision), World Anvil/Obsidian Portal (density), Dark Alliance/Idle Champions (negative or irrelevant).
