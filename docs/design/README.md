# Design · what is canonical

The approved design is the prototype in [`prototype/`](prototype/) (owner, 2026-11-02, direction rows 27–29). Every new screen copies it; nothing else in `docs/design/` overrides it.

| Where                                                                                                    | What it is                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`prototype/`](prototype/)                                                                               | 102 static pages, one per screen and state (desktop and phone Play variants, dialogs, empty, loading, error, 404). Open any `.html` in a browser. `css/` holds the shared styles, `img/rooms/` the five room backgrounds (option D, with `PROVENANCE.md`). |
| [`copy/voice-guide.md`](copy/voice-guide.md)                                                             | How Folio talks, in IT and EN, with 10 do/don't examples.                                                                                                                                                                                                  |

When a screen is built, its i18n shard takes the strings from here.                                                                                                                    |
| [`logo/`](logo/)                                                                                         | The Inciso logo in three cuts, with provenance.                                                                                                                                                                                                            |
| [`new-ui-build-plan.md`](new-ui-build-plan.md), [`new-ui-wiring.md`](new-ui-wiring.md)                   | Build order and the engine seams each screen reads.                                                                                                                                                                                                        |
| [`direction-2026-10-23/`](direction-2026-10-23/)                                                         | The boards behind the direction decisions; history, superseded where the prototype differs.                                                                                                                                                                |

**The rules the prototype was checked against** (all 102 pages × 1440, 1100, 768, 390, 320 px and 200% zoom, in Italian and English): no horizontal scroll, nothing clipped or cut with «…», no overlaps or text out of its box, no lonely last word, numbers kept with their units, text readable by real glyph height (≥ 12 px), AA contrast, 4/8 px grid, one panel-header component, touch targets ≥ 40 px, visible focus, every string translated, and none of the banned terms (product names, real people, internal codes, dev words, «!»). The design-system slice ports the same checks into the Playwright suite, so they guard the product too.

**Archive.** Older explorations stay out of the repo: the owner's archive is `~/Workspace/Codex/folio-design-scratch/` (prototype sources, the generator scripts, review boards).
