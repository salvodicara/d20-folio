# Surfaces — design vision checklist

Owner, 2026-10-13: every screen follows ONE design vision — dialogs, menus, everything.
This is the list of every user-facing surface, generated from the code by
`scripts/design/surface-inventory.ts`; `tests/unit/surface-inventory.guard.test.ts` fails
when the code gains a surface this table does not list, or the table lists one the code no
longer has. Run `pnpm exec node --experimental-strip-types scripts/design/surface-inventory.ts`
to print the rows to add.

A row is `done` only when it is checked in the vision on phone + laptop, dark + light, with
before/after shots shown to the owner. `state:` rows are written by hand: states inside a
surface (edit mode, dying, a wizard step) that the scan cannot see.

Kinds: `route` page · `panel` sheet tab / creation step · `tabs` tab bar · `dialog` modal ·
`popover` · `menu` · `listbox` · `picker` · `tooltip` · `notice` toast/banner · `empty` /
`loading` states · `state` hand-written.
