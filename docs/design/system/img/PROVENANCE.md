# Prototype images: provenance

- **Made with:** OpenAI image generation through the owner's ChatGPT subscription (Codex CLI
  bundled in ChatGPT.app, `codex exec`), 2026-10-16, for d20 Folio.
- **Prompting:** original subjects only. Every prompt forbade imitating any existing game,
  franchise, film, artist or real person, and forbade text, logos and frames.
- **Rights:** OpenAI's terms assign the output to the user, so the owner holds these images.
  No third-party asset is included.
- **Files:**
  - `portrait-selene.webp`: the demo character's portrait.
  - `icon-*.webp`: one painted icon per action, generated as a single consistent set.
- **Processing:** PNG 1024×1024 → WebP (portrait 480 px at q82, icons 128 px at q85).
- **Use:** prototypes only. App delivery follows the hero-art rule: never precached, cached at
  runtime.
- `campaign-war-room.webp` and `login-sanctum.webp`: crops of the hero-art series on branch
  `design/b-play-combat` (`public/assets/backgrounds/HERO-ART.md` there records the same
  provenance: owner's ChatGPT subscription via Codex, 2026-10-16, original subjects).
